## 套接字那一层

`server.c` 只做五步：`socket` → `bind` → `listen` → `accept` → `read` / `write`。

我把它绑在 `127.0.0.1:8080`。学习用的服务不需要让局域网访问。绑定地址写宽了，这个练习就变成对外开端口。

`accept` 之后读到的是一段文本，第一行类似 `GET / HTTP/1.1`。所谓 HTTP 响应，在这里就是我自己拼出来的状态行、头和 JSON 正文，然后 `write` 回去，再 `close`。一次只处理一个连接，所以它还不是能并发的服务器。这一步要确认的是：我能看见请求，也能按格式写回响应。

## Python 这一层

`app.py` 用标准库 `http.server`，没有先上框架。对应关系是：

- `GET /`：服务是否在跑，以及有哪些路径
- `GET /health`：健康检查
- `POST /api/chat`：把 `prompt` 转给 DeepSeek；请求里带了 Gemini 模型名时走 Gemini
- 其他路径：404

浏览器从 Live Server 的页面去调 `127.0.0.1:8000`，端口不同，会先发 `OPTIONS`。来源不在允许列表里就回 403，不是对所有来源放开。允许的来源默认只有本机。

监听地址同样默认 `127.0.0.1`。要改地址必须自己设 `HOST`，避免为了图方便写成对全网监听。
